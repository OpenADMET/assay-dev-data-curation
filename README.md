# Data curation for initial assay development with Octant Bio

Aggregation of compounds known to be active against below targets for assay development, retrosynthetic analysis and pure-crude correlation measurements. Data was scraped from FDA resources, ChEMBL, and known summary literature.

This collection was used to inform reference compound purchasing for assay development. A crude metric (`appears_in_N_datasets`) was used to quantify frequently assayed compounds by aggregating membership in assays across ChEMBL and also some scraped literature. 

## Targets

* CYP1A2
* CYP2C9
* CYP2D6
* CYP3A4
* CYP2J2
* PXR
* AHR
